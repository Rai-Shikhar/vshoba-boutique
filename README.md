# vshoba-boutique

## Deploying to Render

The service runs via **Docker** (Render auto-detects the `Dockerfile`). The `render.yaml` blueprint declares everything; the Docker image builds the Spring Boot jar, so no build/buildpack config is needed.

1. Push this repo to GitHub (if not already).
2. On Render: **New + → Blueprint** → connect this repo (Render reads `render.yaml`).
3. The web service and env vars are created automatically — no build or start command to type.
4. On Render: **New + → PostgreSQL** → create free database.
5. In the web service's **Environment** tab, fill the blank vars from the Postgres dashboard:
   - Copy the **Internal Database URL** (format `postgres://USER:PASSWORD@HOST:5432/DBNAME`)
   - `DATABASE_URL` is **not needed** — the JDBC URL has a built-in fallback in `application-prod.properties` pointing at the Render Postgres
   - `SPRING_DATASOURCE_USERNAME` = `USER` from the URL
   - `SPRING_DATASOURCE_PASSWORD` = `PASSWORD` from the URL
   - `SPRING_PROFILES_ACTIVE=prod` (set automatically — verify it's present)
   - `RAZORPAY_KEY` / `RAZORPAY_SECRET` (test mode values initially)
   - `JWT_SECRET` (auto-generated by the blueprint)
6. **Deploy.**
   - Note: free tier sleeps after 15 min inactivity (cold start on next request).
   - The free Postgres database expires after 90 days.
